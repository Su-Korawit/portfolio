# ระบบ Comment สำหรับบทความและโปรเจกต์: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ให้ผู้อ่านคอมเมนต์ใต้บทความและโปรเจกต์ได้โดยไม่ต้องสมัครสมาชิก ขึ้นเว็บทันที (post-moderate) เจ้าของเว็บลบทีหลังได้ผ่าน `/admin/comments`

**Architecture:** ตาราง SQLite ใหม่ตารางเดียว (`comments`) ผูกกับ `posts`/`projects` ที่มีอยู่แล้ว โมดูลเล็กๆ อิสระสามตัว (`nickname.js` สุ่มชื่อ, `rate-limit.js` กัน spam, `comment-cookies.js` จัดการ cookie ระบุตัวตน+CSRF) ที่ประกอบกันใน `src/routes/public.js` เป็น route ใหม่ 3 เส้นทาง (`POST .../comments` ของบทความและโปรเจกต์ กับ `POST /:lang/reroll-nickname`) และ `src/routes/admin-comments.js` สำหรับหน้าแอดมิน ทุกอย่าง render ฝั่ง server ด้วย EJS เดิม ไม่มี client framework ใหม่ มี JS เสริมเล็กน้อยแบบ progressive enhancement

**Tech Stack:** Express 5, EJS, `@libsql/client` ผ่าน `src/db.js`, `node:test` + `node:assert/strict`, ไม่เพิ่ม npm dependency ใหม่

**Spec:** [docs/superpowers/specs/2026-09-22-comments-design.md](../specs/2026-09-22-comments-design.md)

## Global Constraints

- ไม่เพิ่ม npm dependency ใหม่ (spec: กัน spam ด้วย honeypot + rate-limit ในหน่วยความจำ, CSRF ด้วย double-submit cookie มือเขียน ไม่ใช้ `csurf`/captcha)
- Comment ผูกกับ `post_id`/`project_id` เท่านั้น ไม่ผูกกับภาษา (spec ส่วนที่ 1)
- ไม่มี field อีเมล/เว็บไซต์ของผู้คอมเมนต์ ไม่มี threading ไม่มี pagination (spec ภาคผนวก ก)
- ชื่อผู้คอมเมนต์สุ่มเสมอ ไม่มีช่องให้พิมพ์ชื่อเอง รูปแบบ `<คำคุณศัพท์ไทย><เลข 2-3 หลัก>` เช่น `ใจดี482` (spec ส่วนที่ 2)
- เนื้อหาคอมเมนต์เป็น plain text ล้วน render ด้วย `<%= %>` เท่านั้น ห้ามใช้ `<%-` กับข้อมูลจาก comment ทุกจุด (spec ส่วนที่ 5)
- ต้อง `app.set('trust proxy', 1)` ก่อน rate-limit จะอ้างอิง IP จริงได้ (spec: สิ่งที่เจ้าของต้องทำ)
- UI ใช้ design token เดิมทั้งหมด (`--bg`, `--surface`, `--border`, `--text-muted`, `--accent`, `--r-sm`, `--sp-*`) ไม่เพิ่มฟอนต์ใหม่ (spec ส่วนที่ 6)
- ทุกไฟล์ทดสอบใหม่ต่อเลขจาก `test/17-consent-privacy.test.js` เป็นต้นไป ใช้ pattern เดียวกับไฟล์เทสต์ที่มีอยู่ (`const h = await start(); try { ... } finally { await h.stop(); }`, ไม่ใช้ subtest)

```js
const test = require('node:test');
const assert = require('node:assert/strict');
const { start, insertPost, insertProject, run, get } = require('./helpers');

test('18 comments schema', async () => {
  const h = await start();
  try {
    const postId = await insertPost({ th: { slug: 'a', title: 'A' } });
    let { lastID } = await run(
      "INSERT INTO comments (post_id, author_name, body) VALUES (?, 'ใจดี99', 'hello')",
      [postId]
    );
    let row = await get('SELECT * FROM comments WHERE id = ?', [lastID]);
    assert.equal(row.post_id, postId);
    assert.equal(row.project_id, null);
    assert.equal(row.body, 'hello');
    assert.ok(row.created_at);

    const projectId = await insertProject({ th: { slug: 'p', title: 'P' } });
    ({ lastID } = await run(
      "INSERT INTO comments (project_id, author_name, body) VALUES (?, 'ใจดี99', 'hi')",
      [projectId]
    ));
    row = await get('SELECT * FROM comments WHERE id = ?', [lastID]);
    assert.equal(row.project_id, projectId);
    assert.equal(row.post_id, null);

    // CHECK: exactly one of post_id/project_id must be set
    await assert.rejects(
      run("INSERT INTO comments (author_name, body) VALUES ('ใจดี99', 'neither')")
    );
    await assert.rejects(
      run(
        'INSERT INTO comments (post_id, project_id, author_name, body) VALUES (?, ?, ?, ?)',
        [postId, projectId, 'ใจดี99', 'both']
      )
    );

    // ON DELETE CASCADE, same convention as post_tags/project_tags
    await run('DELETE FROM posts WHERE id = ?', [postId]);
    assert.equal(await get('SELECT id FROM comments WHERE post_id = ?', [postId]), undefined);
    await run('DELETE FROM projects WHERE id = ?', [projectId]);
    assert.equal(await get('SELECT id FROM comments WHERE project_id = ?', [projectId]), undefined);
  } finally {
    await h.stop();
  }
});
```

```sql
CREATE TABLE IF NOT EXISTS comments (
  id          INTEGER PRIMARY KEY,
  post_id     INTEGER REFERENCES posts(id) ON DELETE CASCADE,
  project_id  INTEGER REFERENCES projects(id) ON DELETE CASCADE,
  author_name TEXT NOT NULL,
  body        TEXT NOT NULL,
  created_at  TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
  CHECK ((post_id IS NULL) <> (project_id IS NULL))
);
CREATE INDEX IF NOT EXISTS comments_post ON comments (post_id, created_at);
CREATE INDEX IF NOT EXISTS comments_project ON comments (project_id, created_at);
```

```js
// Rate-limit ในหน่วยความจำต่อ IP (spec docs/superpowers/specs/2026-09-22-comments-design.md ส่วนที่ 3).
// ไม่เก็บ IP ลง DB, ไม่มีการล้าง Map แบบ cron แยก เพราะ filter() ตอน allow() ทำหน้าที่นั้นอยู่แล้ว
// และ traffic ของเว็บนี้เล็กพอที่จำนวนคีย์ค้างจะไม่กลายเป็นปัญหาหน่วยความจำจริง
const WINDOW_MS = 10 * 60 * 1000;
const MAX_PER_WINDOW = 5;

const hits = new Map();

// `now` รับเข้ามาได้เพื่อให้เทสต์ไม่ต้องรอ 10 นาทีจริง production เรียกโดยไม่ส่ง now ก็ได้
function allow(ip, now = Date.now()) {
  const recent = (hits.get(ip) || []).filter(t => now - t < WINDOW_MS);
  recent.push(now);
  hits.set(ip, recent);
  return recent.length <= MAX_PER_WINDOW;
}

module.exports = { allow, WINDOW_MS, MAX_PER_WINDOW };
```

- [ ] **Step 1: เขียนเทสต์ที่ยังพัง**

สร้าง `test/21-comment-cookies.test.js`:

```js
const test = require('node:test');
const assert = require('node:assert/strict');
const { ensureCommentIdentity, checkCsrf, clearNickname, NICK_COOKIE, CSRF_COOKIE } = require('../src/comment-cookies');

function fakeReqRes(signedCookies = {}, body = {}) {
  const cookies = [];
  const req = { signedCookies, body };
  const res = {
    locals: {},
    cookie: (name, value, opts) => cookies.push({ name, value, opts }),
    clearCookie: (name, opts) => cookies.push({ name, value: null, opts })
  };
  return { req, res, cookies };
}

test('21 comment cookies', () => {
  // ไม่มีคุกกี้เลย: สุ่มชื่อและ csrf ใหม่ทั้งคู่ แล้วตั้งคุกกี้
  {
    const { req, res, cookies } = fakeReqRes();
    ensureCommentIdentity(req, res, () => {});
    assert.match(res.locals.nickname, /^[ก-๙]+[1-9][0-9]{1,2}$/);
    assert.match(res.locals.csrfToken, /^[A-Za-z0-9_-]{32,}$/);
    assert.ok(cookies.some(c => c.name === NICK_COOKIE && c.value === res.locals.nickname));
    assert.ok(cookies.some(c => c.name === CSRF_COOKIE && c.value === res.locals.csrfToken));
  }

  // คุกกี้เดิมถูกต้อง: ใช้ซ้ำ ไม่ตั้งคุกกี้ใหม่
  {
    const { req, res, cookies } = fakeReqRes({ [NICK_COOKIE]: 'ใจดี482', [CSRF_COOKIE]: 'a'.repeat(32) });
    ensureCommentIdentity(req, res, () => {});
    assert.equal(res.locals.nickname, 'ใจดี482');
    assert.equal(res.locals.csrfToken, 'a'.repeat(32));
    assert.equal(cookies.length, 0);
  }

  // คุกกี้ nickname ถูกแก้ให้ผิดรูปแบบ: สุ่มใหม่เงียบๆ ไม่ error
  {
    const { req, res } = fakeReqRes({ [NICK_COOKIE]: '<script>alert(1)</script>' });
    ensureCommentIdentity(req, res, () => {});
    assert.notEqual(res.locals.nickname, '<script>alert(1)</script>');
    assert.match(res.locals.nickname, /^[ก-๙]+[1-9][0-9]{1,2}$/);
  }

  // next() ถูกเรียกเสมอ
  {
    const { req, res } = fakeReqRes();
    let called = false;
    ensureCommentIdentity(req, res, () => { called = true; });
    assert.equal(called, true);
  }

  // checkCsrf: ตรงกันผ่าน ไม่ตรง/ไม่มีคุกกี้ไม่ผ่าน
  assert.equal(checkCsrf({ signedCookies: { [CSRF_COOKIE]: 'abc' }, body: { _csrf: 'abc' } }), true);
  assert.equal(checkCsrf({ signedCookies: { [CSRF_COOKIE]: 'abc' }, body: { _csrf: 'xyz' } }), false);
  assert.equal(checkCsrf({ signedCookies: {}, body: { _csrf: 'abc' } }), false);
  assert.equal(checkCsrf({ signedCookies: { [CSRF_COOKIE]: 'abc' }, body: {} }), false);

  // clearNickname: เรียก res.clearCookie ด้วยชื่อและ attribute ที่ตรงกับตอนตั้ง (path ต้องตรงถึงจะล้างได้จริง)
  {
    const { res, cookies } = fakeReqRes();
    clearNickname(res);
    assert.equal(cookies.length, 1);
    assert.equal(cookies[0].name, NICK_COOKIE);
    assert.equal(cookies[0].opts.path, '/');
  }
});
```

```js
const crypto = require('node:crypto');
const nickname = require('./nickname');

const NICK_COOKIE = 'ta_nick';
const CSRF_COOKIE = 'ta_csrf';

// attribute เดียวกับที่ ta_admin ใช้ใน src/routes/admin.js (signed, httpOnly, sameSite lax) ต่างกันแค่ path:
// คุกกี้พวกนี้ใช้ทั้งเว็บสาธารณะ ไม่ใช่แค่ /admin
const ATTRS = {
  httpOnly: true,
  sameSite: 'lax',
  secure: process.env.NODE_ENV === 'production',
  path: '/',
  signed: true
};
const NICK_MAX_AGE = 365 * 864e5;
const CSRF_MAX_AGE = 864e5;
const CSRF_PATTERN = /^[A-Za-z0-9_-]{32,}$/;

// ตั้ง res.locals.nickname/csrfToken ให้ฟอร์ม comment ใช้ และตั้งคุกกี้ใหม่เฉพาะตอนที่ยังไม่มีหรือค่าที่มีผิดรูปแบบ
// (เช่น ถูกแก้มือ หรือคุกกี้เก่าจากก่อนฟีเจอร์นี้). รันเฉพาะ route ที่มีฟอร์ม comment ไม่ใช่ทุกหน้า.
function ensureCommentIdentity(req, res, next) {
  let nick = req.signedCookies[NICK_COOKIE];
  if (!nickname.isValid(nick)) {
    nick = nickname.generate();
    res.cookie(NICK_COOKIE, nick, { ...ATTRS, maxAge: NICK_MAX_AGE });
  }
  res.locals.nickname = nick;

  let csrf = req.signedCookies[CSRF_COOKIE];
  if (typeof csrf !== 'string' || !CSRF_PATTERN.test(csrf)) {
    csrf = crypto.randomBytes(24).toString('base64url');
    res.cookie(CSRF_COOKIE, csrf, { ...ATTRS, maxAge: CSRF_MAX_AGE });
  }
  res.locals.csrfToken = csrf;

  next();
}

// double-submit cookie: ฟิลด์ที่ผู้ใช้ส่งมาต้องตรงกับคุกกี้ signed ที่เบราว์เซอร์แนบมาเอง
// เว็บข้ามโดเมนอ่านคุกกี้นี้ไม่ได้ (ไม่ใช่ JS ของเว็บนี้) และเดาค่าที่ถูกต้องไม่ได้เพราะสุ่มด้วย crypto.randomBytes
function checkCsrf(req) {
  const cookie = req.signedCookies[CSRF_COOKIE];
  return typeof cookie === 'string' && cookie.length > 0 && cookie === req.body._csrf;
}

function clearNickname(res) {
  res.clearCookie(NICK_COOKIE, ATTRS);
}

module.exports = { ensureCommentIdentity, checkCsrf, clearNickname, NICK_COOKIE, CSRF_COOKIE };
```

```js
  const tr = await get(
    "SELECT * FROM post_translations WHERE lang = ? AND slug = ? AND status = 'published'",
    [lang, slug]

    "SELECT lang, slug FROM post_translations WHERE post_id = ? AND status = 'published' ORDER BY lang DESC",
    [tr.post_id]
  );
  const tagRows = await all(
    `SELECT tg.slug, tg.name_th, tg.name_en
     FROM post_tags pt JOIN tags tg ON tg.id = pt.tag_id
     WHERE pt.post_id = ? ORDER BY tg.slug`,
    [tr.post_id]
  );
```

```js
const COMMENT_MIN = 2;
const COMMENT_MAX = 2000;

// คืนค่า { ok: true, value } หรือ { ok: false, key } โดย key เป็นคีย์ของ src/strings.js
function validateCommentBody(raw) {
  const body = typeof raw === 'string' ? raw.trim() : '';
  if (body.length < COMMENT_MIN) return { ok: false, key: 'commentTooShort' };
  if (body.length > COMMENT_MAX) return { ok: false, key: 'commentTooLong' };
  return { ok: true, value: body };
}

// ตรวจ honeypot -> CSRF -> rate-limit -> ความยาวข้อความ ตามลำดับนี้เสมอ (spec ส่วนที่ 4): สามอย่างแรกตอบเหมือน
// สำเร็จเงียบๆ โดยไม่บันทึกอะไร เพื่อไม่ให้เป็นสัญญาณบอกบอทว่าโดนจับได้เพราะอะไร มีแค่ผิดความยาวเท่านั้นที่บอกผู้ใช้จริง
async function submitComment(req, res, column, id) {
  if (typeof req.body.website === 'string' && req.body.website !== '') return { status: 'silent' };
  if (!commentCookies.checkCsrf(req)) return { status: 'silent' };
  if (!rateLimit.allow(req.ip)) return { status: 'silent' };
  const parsed = validateCommentBody(req.body.body);
  if (!parsed.ok) return { status: 'invalid', key: parsed.key };
  await run(`INSERT INTO comments (${column}, author_name, body) VALUES (?, ?, ?)`, [id, res.locals.nickname, parsed.value]);
  return { status: 'ok' };
}

// เชื่อถือเฉพาะ path ของ Referer ไม่สนใจ host เลย: ค่าที่คืนใช้สร้าง relative redirect กลับเข้าเว็บนี้เองเท่านั้น
// (ไม่เคยเอา host ของ Referer ไปต่อเป็น URL ปลายทาง) จึงไม่มีช่อง open redirect ให้ต้องตรวจ host เพิ่ม
// เช็คแค่รูปแบบ path ว่าเป็นหน้าในเว็บนี้จริง (ขึ้นต้นด้วย /th/ หรือ /en/) ไม่งั้น fallback ไปหน้าแรกของภาษานั้น
function safeReferer(req, lang) {
  const header = req.get('Referer') || '';
  try {
    const { pathname, search } = new URL(header);
    if (/^\/(th|en)\//.test(pathname)) return pathname + search;
  } catch {}
  return '/' + lang;
}
```

```js
// วนไล่ code point ของชื่อรวมกันแล้ว mod 6 -> class avatar-0 ถึง avatar-5 (spec ส่วนที่ 6)
// ไม่ต้องเป๊ะทางสถิติ แค่ deterministic พอให้คนเดิมได้สีเดิมเสมอ
function avatarIndex(name) {

  return hash;
}
```

```js
const express = require('express');
const { run, all } = require('../db');

const router = express.Router();

// :id ต้องเป็นเลขจำนวนเต็มบวก แบบเดียวกับ src/routes/admin-projects.js/admin.js
function parseId(value) {
  return /^[1-9][0-9]*$/.test(value) && Number.isSafeInteger(Number(value)) ? Number(value) : null;
}

// join กับ translation ทั้งสองภาษาของทั้งสองประเภทเนื้อหา: comment มีแค่ post_id หรือ project_id อย่างเดียว
// (CHECK constraint ของตาราง) จึงมีแค่ฝั่งเดียวที่ไม่เป็น NULL ทั้งหมด link_lang/slug เลือกเฉพาะ translation
// ที่ยังเผยแพร่อยู่ ส่วน title ใช้ translation ไหนก็ได้ที่มี (กันกรณีถูกเปลี่ยนกลับเป็นร่างแล้วไม่มีลิงก์ให้กด)
const LIST_SQL = `
  SELECT c.id, c.author_name, c.body, c.created_at,
         CASE WHEN c.post_id IS NOT NULL THEN 'post' ELSE 'project' END AS kind,
         COALESCE(pt_th.title, pt_en.title, pjt_th.title, pjt_en.title) AS title,
         CASE
           WHEN pt_th.status = 'published' THEN 'th' WHEN pt_en.status = 'published' THEN 'en'
           WHEN pjt_th.status = 'published' THEN 'th' WHEN pjt_en.status = 'published' THEN 'en'
           ELSE NULL
         END AS link_lang,
         CASE
           WHEN pt_th.status = 'published' THEN pt_th.slug WHEN pt_en.status = 'published' THEN pt_en.slug
           WHEN pjt_th.status = 'published' THEN pjt_th.slug WHEN pjt_en.status = 'published' THEN pjt_en.slug
           ELSE NULL
         END AS slug
  FROM comments c
  LEFT JOIN post_translations pt_th ON pt_th.post_id = c.post_id AND pt_th.lang = 'th'
  LEFT JOIN post_translations pt_en ON pt_en.post_id = c.post_id AND pt_en.lang = 'en'
  LEFT JOIN project_translations pjt_th ON pjt_th.project_id = c.project_id AND pjt_th.lang = 'th'
  LEFT JOIN project_translations pjt_en ON pjt_en.project_id = c.project_id AND pjt_en.lang = 'en'
  ORDER BY c.created_at DESC`;

router.get('/', async (req, res) => {
  const comments = await all(LIST_SQL);
  res.render('admin/comments', { comments });
});

router.post('/:id/delete', async (req, res, next) => {
  const id = parseId(req.params.id);
  if (!id) return next();
  const { changes } = await run('DELETE FROM comments WHERE id = ?', [id]);
  if (changes === 0) return next();
  res.redirect(303, '/admin/comments');
});

module.exports = router;
```
